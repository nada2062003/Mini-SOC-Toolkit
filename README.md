# Mini SOC Toolkit

A Python-based cybersecurity toolkit that combines multiple security utilities into a single command-line application.

This project was developed to practice Python programming while applying fundamental cybersecurity concepts such as network scanning, log analysis, file integrity monitoring, phishing detection, and password security.

## Security Tools

The toolkit includes the following modules:

### 1. Password Strength Checker
Analyzes password strength based on security criteria such as length, uppercase and lowercase letters, numbers, and special characters.

### 2. Secure Password Generator
Generates strong and randomized passwords using different character combinations.

### 3. File Integrity Checker
Uses cryptographic hashing to detect whether a file has been modified.

### 4. Security Log Analyzer
Analyzes security log files and identifies potentially suspicious activity.

### 5. Network Port Scanner
Scans a target host for open network ports using Python socket programming.

> Only scan systems and networks you own or have explicit permission to test.

### 6. IP Information Checker
Analyzes and validates IP address information for basic network investigation.

### 7. Phishing URL Analyzer
Examines URLs for characteristics commonly associated with suspicious or phishing links.

## Technologies Used

- Network Security Fundamentals
